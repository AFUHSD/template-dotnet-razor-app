# Security policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue,
pull request or discussion for a security problem.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the report,
keep you updated while we investigate, and credit you in the fix unless you ask us not to.

## Scope

This repository is a starter template. Reports about the template itself (authentication wiring, health
endpoints, defaults that fail open) are in scope. Apps created from it are maintained separately.
